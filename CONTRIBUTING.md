# Contribuir al repositorio

1. Fork + crea una rama `feature/mi-cambio`
2. Haz cambios en `notebooks/` o `streamlit_app/`
3. Ejecuta tests / revisa notebooks localmente
4. Abre Pull Request dirigido a `main` con descripción clara y checklist
5. Etiqueta a los revisores del equipo

Normas:
- Buenas prácticas de commits: usar tipos (feat, fix, chore, docs).
- Un notebook por PR si cambia un notebook grande.
