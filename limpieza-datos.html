🧼 Limpieza y Preparación del Dataset del Titanic#

Este notebook tiene como objetivo preparar el dataset del Titanic para análisis exploratorio y modelado predictivo. A continuación se detallan los pasos realizados:

📥 1. Carga del Dataset#

Se comienza cargando el archivo CSV que contiene los datos de los pasajeros del Titanic.

import pandas as pd

# Cargar el archivo CSV
df = pd.read_csv('../datasets/Titanic-Dataset.csv')

🧹 2. Eliminación de Columnas Irrelevantes#

Se eliminan columnas que no aportan valor directo al análisis o que contienen información difícil de procesar sin un tratamiento adicional. Estas incluyen identificadores únicos, nombres, números de ticket y cabinas.

# Eliminar columnas que no son útiles para el análisis
df.drop(['PassengerId', 'Name', 'Ticket', 'Cabin'], axis=1, inplace=True)

🧩 3. Tratamiento de Valores Faltantes#

Se manejan los valores nulos en las siguientes columnas:

  • Edad (Age): se reemplaza con la mediana para mantener la distribución.

  • Tarifa (Fare): se reemplaza con la mediana.

  • Puerto de embarque (Embarked): se reemplaza con la moda (valor más frecuente).

# Imputar valores faltantes
df['Age'].fillna(df['Age'].median(), inplace=True)
df['Fare'].fillna(df['Fare'].median(), inplace=True)
df['Embarked'].fillna(df['Embarked'].mode()[0], inplace=True)

🔄 4. Conversión de Variables Categóricas#

Para facilitar el análisis y modelado, se convierten las variables categóricas en numéricas:

  • Sexo (Sex): se codifica como 0 para hombre y 1 para mujer.

  • Puerto de embarque (Embarked): se transforma en variables dummy (one-hot encoding), eliminando una categoría para evitar multicolinealidad.

# Convertir 'Sex' a variable numérica
df['Sex'] = df['Sex'].map({'male': 0, 'female': 1})

# Convertir 'Embarked' a variables dummy
df = pd.get_dummies(df, columns=['Embarked'], drop_first=True)
